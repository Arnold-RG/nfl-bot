# Nutrition Fitness Loop (Fuel)

NFL BOT’s member experience is aligned with [CalorieLab](https://calorielab.app/)-style nutrition UX.

## App structure

| Tab | Screen |
|-----|--------|
| **Home** | Greeting, week dates, kcal ring, macros, water, Add Meal, meal preview |
| **Diary** | Full meal list + health score chips + scan CTA |
| **Add** | Opens meal scan (Snap → Analyze → Confirm) |
| **Body** | Weight, BMI, goal timeline, weekly calorie bars |
| **Profile** | Account, AI Coach, Train extras |

## Accuracy loop

1. Snap meal photo  
2. Analyze with AI vision  
3. Edit portions (macros auto-scale)  
4. Confirm into the diary  

AI estimates are never logged without user confirmation.

## Theme

Light CalorieLab surfaces (`labBg` / white cards / black CTAs / orange kcal accent).  
Train & Coach remain available from Profile.
