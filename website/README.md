# Elvora — public site

The marketing site for the Flutter app.

**Live:** https://arnold-rg.github.io/nfl-bot/

The web app is served beside it at `/app/` by the Pages workflow. Privacy is `privacy.html`. `robots.txt` and `sitemap.xml` ship with the site.

## Local

From this folder:

```bash
python -m http.server 5500
```

Open http://127.0.0.1:5500/
